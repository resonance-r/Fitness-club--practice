# Bootstrap Practice Website

This repository contains a simple website built using Bootstrap, HTML, and CSS as a practice project.

## Description

A basic website created to practice fundamental Bootstrap layout, components, and styling. It serves as a learning exercise for front-end web development.

## Usage

Feel free to explore the HTML and CSS files to see how Bootstrap is implemented. You can also clone this repository and open the `index.html` file in your web browser to view the website.

1.  Clone this repository to your local machine:
    ```bash
    git clone <repository_url>
    ```
2.  Navigate to the project directory:
    ```bash
    cd bootstrap-practice-website
    ```
3.  Open the `index.html` file in your web browser to view the website.

## Technologies Used

* HTML
* CSS
* Bootstrap
